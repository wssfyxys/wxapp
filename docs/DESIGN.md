# 设计规范(微信小程序适配版)

本规范定义项目的视觉语言。**所有页面开发前必须先读本文件**,样式一律引用 `styles/tokens.wxss` 中的变量和公共类,禁止在页面里自造颜色、圆角、阴影。

## 1. 设计核心:两条铁律

1. **品牌渐变是唯一的装饰系统**:橙 → 品红 → 长春花三色渐变(`#fc4c02 → #ef2cc1 → #bdbbff`)作为整体使用,只出现在 hero 级别的大图形上。禁止拆成单色填充、禁止调换色站顺序、禁止加第四色、禁止缩小成图标。
2. **表面只有两种,无中间灰**:深色画布 `#010120` 与白色画布 `#ffffff` 交替形成区块节奏(hero 深色 → 内容白色 → 某区块深色)。除此之外唯一的软表面是 `#ebebeb`,仅用于表头行、开关轨道、1px 分隔线。

## 2. 颜色令牌

| 令牌 | 值 | 用途 | 禁止事项 |
|------|------|------|------|
| `--color-primary` | `#000000` | 唯一主 CTA 色(黑色按钮) | 一屏只允许一个黑色主按钮 |
| `--brand-gradient` | 三色渐变 | hero 大图形 | 见第 1 条铁律 |
| `--color-accent-mint` | `#c8f6f9` | hero 次级按钮、统计卡 | 不要当普通状态色用 |
| `--color-accent-periwinkle` | `#bdbbff` | 渐变第 3 站、统计卡软填充 | — |
| `--color-canvas` | `#ffffff` | 白色区块背景 | — |
| `--color-canvas-dark` | `#010120` | 深色区块背景 | — |
| `--color-hairline` | `#ebebeb` | 1px 分隔线、表头、浅底描边 | — |
| `--color-surface-dark-soft` | `#26263a` | 深底分隔线、深底徽章 | — |
| `--color-ink` | `#000000` | 浅底所有标题正文 | — |
| `--color-body` | `#999999` | 次级文字、mono 眉标 | 深浅底各有一个对应次级色,勿混用 |
| `--color-on-dark` | `#ffffff` | 深底所有文字 | — |

语义色(成功/失败/警告)项目未定义,使用框架默认即可,不要新造强调色——三色渐变 + 薄荷色就是全部装饰色板。

## 3. 字体系统:两个声部

**显示字体**(开源替代:Inter 400/500,启用 `font-feature-settings: "ss01"`):承担所有标题、正文、叙述性文字。

**等宽字体**(开源替代:JetBrains Mono 500):承担所有**技术标签**——区块眉标、按钮文字、表头单元格,一律大写、字距为正。

三条不可违反的搭配规则:

- 显示字体只做叙述,等宽字体只做标签;等宽不能排段落,显示字体(非 mono 场景)不能排按钮标签
- 负字距只给显示字体(标题越大约紧);等宽字体用小正字距——两者反了就是错的
- 标题永远是句首大写,所有"全大写"的时刻都属于等宽字体

字阶(rpx = 设计稿 px × 2):

| 类名 | 字号 | 字重 | 用途 |
|------|------|------|------|
| `.t-display-xxl` | 128rpx | 500 | hero 主标题 |
| `.t-display-xl` | 80rpx | 500 | 区块标题 |
| `.t-display-lg` | 56rpx | 500 | 子标题、统计大数字 |
| `.t-display-md` | 44rpx | 500 | 卡片标题 |
| `.t-body-lg` / `.t-body-md` | 36 / 32rpx | 400 | 引导段 / 正文 |
| `.t-caption` | 28rpx | 400 | 细则、页脚次级 |
| `.t-mono-button` + `.font-mono` | 32rpx | 500 | 按钮标签 |
| `.t-mono-eyebrow` + `.eyebrow` | 22rpx | 500 | 区块眉标、表头 |

字重只用 400 和 500,全系统不出现 700。

## 4. 圆角与阴影

| 令牌 | 值(rpx) | 用途 |
|------|------|------|
| `--rounded-sm` | 8 | 规范圆角:按钮、卡片、表格行、徽章 |
| `--rounded-xs` | 3.25 | 定价页内层小胶囊、描边按钮 |
| `--rounded-md` | 16 | 功能 tab 胶囊 |
| `--rounded-full` | 9999 | **仅**悬浮圆形按钮,全系统唯一全胶囊形状 |

阴影规则:**浅底卡片一律不投影**,靠 1px hairline 描边和区块明暗对比区分层级;柔和投影 `--shadow-soft`(品牌深蓝染色)只给悬浮元素(悬浮客服按钮、吸底栏)。

## 5. 间距与布局

- 基数 4px,令牌:4 / 8 / 12 / 16 / 20 / 24 / 32 / 44 / 48 / 80(px,×2 转 rpx)
- 区块上下留白 80px(`.band-dark` / `.band-light` 已内置 160rpx)
- 卡片内边距 24px(48rpx),统计卡 32px(64rpx),给大数字呼吸感
- 容器上限 1280px 居中;区块颜色贴边通栏,内容居中
- 表格行距收紧(12px 垂直),让表格读起来像数据表而不是营销组件

## 7. Do / Don't 速查

**要:**
- 主 CTA 全部用黑色 `.btn-primary`,一屏一个
- 每个区块配 `.eyebrow` 眉标,按钮文字全大写 mono
- 深色 → 白色 → 深色地交替区块,用明暗对比代替阴影
- 卡片统一 8rpx 圆角 + 1px 描边
- 长页底部加 `.wordmark-banner` 巨型字标收尾

**不要:**
- 引入第五种强调色(三色渐变 + 薄荷就是全部)
- 用等宽字体排段落正文
- 给浅底卡片加投影
- 把主按钮改成全胶囊形(`--rounded-full` 只属于悬浮球)
- 把渐变缩小、拆色、调序
- 标题用全大写、正文居中排在左对齐标题下面

## 8. 代码审查时的样式检查点

PR 审查中(见 `CONTRIBUTING.md`)额外检查:

1. 颜色值是否全部来自 `--color-*` 变量(页面 WXSS 里不允许出现裸的十六进制色值)
2. 是否直接引用了 `tokens.wxss` 的组件类,而不是复制粘贴样式代码
3. 一屏内主按钮是否只有一个黑色
4. 深色区块内的文字是否用了 `--color-on-dark`,分隔线是否用 `--color-surface-dark-soft`
